---
## File an Issue on GitHub
---

For issues with software, please file an [Issue on GitHub](https://github.com/NCAR/DART/issues) 
detailing your issue. Since GitHub issues are viewable by the public, filing
an issue there will help the larger community by providing searchable
documentation of difficulties.

---
## Email us
---

If you are unable to file an issue on Github, please compose an email containing 
descriptions of your computing system, its operating system, the compiler and
your model domain. Send the email to [dart@ucar.edu](dart@ucar.edu).
